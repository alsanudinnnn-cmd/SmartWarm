# SmartWarm

SmartWarm is an IoT-based interactive warm-up game designed to improve athletes' reaction time, agility, and coordination through engaging physical activities. The system integrates an ESP32, Firebase Realtime Database, and Cloudinary to deliver real-time gameplay and leaderboard management.

## Features

- Interactive warm-up game using ESP32
- Random LED checkpoint system
- Real-time leaderboard with Firebase Realtime Database
- Player registration with Cloudinary image upload
- Three difficulty stages
- Live score tracking
- Responsive web dashboard
- Admin management system
